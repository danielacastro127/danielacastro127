## About

Full Stack Developer with 4+ years of experience building production web applications, focused on frontend. My core stack is Angular, React, TypeScript and Node.js, applied to ERP systems for manufacturing, academic platforms and event ticketing.

My most complete project is an event ticketing platform where I architected an interactive SVG seat-selection component with real-time availability, dynamic pricing and a full purchase flow, shared between a public portal and a box office POS.

I design REST APIs, work with SQL and NoSQL databases, write unit and E2E tests with Playwright, and use AI tools like Claude Code in my daily workflow. I have also coordinated Scrum processes and worked directly with clients.

Native Spanish speaker, English B2 (IELTS).
